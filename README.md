# 🌦️ Weather Now

A responsive weather application built using HTML, CSS, and JavaScript that helps users check weather information for a city.

✨ Features
- Search for weather by city name
- Display current weather information
- Show temperature and weather conditions
- Simple and user-friendly interface
- Responsive design for different screen sizes

 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript


🚀 How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Search for a city to view its weather.
